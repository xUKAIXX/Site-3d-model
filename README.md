# Bottom Drop®

Интерактивная подводная галерея: три виниловые фигурки из Бикини Боттом, три разных пьедестала и переход-погружение, привязанный к прокрутке.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

`npm run build` собирает статический сайт в `dist/`. `npm run preview` позволяет проверить эту сборку локально.

## Управление

- Прокручивайте страницу или выбирайте нужного персонажа в нижней навигации.
- Потяните фигурку мышью или пальцем, чтобы повернуть её вместе с пьедесталом. Кнопка со стрелкой по кругу возвращает исходный ракурс.
- С клавиатуры: переведите фокус на сцену с помощью `Tab`, затем используйте стрелки, а для сброса — `Home`.
- Звуковое сопровождение включается только по нажатию на кнопку в шапке.

Модели и пьедесталы собраны программно в Three.js (`src/characters.js`, `src/sculpt.js`, `src/pedestals.js`). На устройствах без WebGL 2 вращение работает через сетку предварительных рендеров тех же моделей. Настройка уменьшенного движения отключает полёт камеры и инерцию.
