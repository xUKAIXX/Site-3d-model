# Bottom Drop®

Интерактивная 3D-галерея: три виниловые фигурки на отдельных пьедесталах и переход-погружение при прокрутке.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

`npm run build` собирает статический сайт в `dist/`. `npm run preview` позволяет проверить эту сборку локально.

## Управление

- Прокручивайте страницу или выбирайте нужного персонажа в нижней навигации.
- Потяните фигурку мышью или пальцем, чтобы повернуть её вместе с пьедесталом. Лупа включает крупный план, кнопка со стрелкой по кругу возвращает исходный ракурс.
- С клавиатуры: переведите фокус на сцену с помощью `Tab`, затем используйте стрелки, а для сброса — `Home`.
- Звуковое сопровождение включается только по нажатию на кнопку в шапке.

Скульптурные поверхности трёх фигурок — индексированные GLB-меши со сжатием Meshopt. В `tools/sculpt.py` описаны формы, объёмные углубления и позы; из этого файла можно пересобрать меши. Одежда, обувь, аксессуары и пьедесталы собираются в Three.js (`src/characters.js`, `src/wardrobe.js`, `src/pedestals.js`).

На устройствах без WebGL 2 вращение работает через сетку предварительных рендеров тех же моделей. Настройка уменьшенного движения отключает полёт камеры и инерцию.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` собирает сайт из исходников и публикует `dist/`. Для первой публикации в настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в поле **Source**. Если первый запуск завершился до включения Pages, перезапустите его во вкладке **Actions**. Адрес сайта появится в результате задачи **Publish to Pages**.
